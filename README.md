## 서비스 소개

**학원 평가 도우미**는 영어 학원에서 모의고사를 본 뒤 하는 채점·성적 정리·결과 분석을 자동으로 해 주는 Agent 기반 웹 서비스입니다.
문제지 PDF, 정답 PDF, OMR 응답 엑셀 파일을 올리면 바로 채점하고, 결과를 엑셀로 내려받을 수 있으며, 채점 결과를 자연어로 묻고 답하는 AI 챗봇을 제공합니다.

## 주요 기능

### 1. 자동 채점
- 정답 PDF에서 문항 번호·정답·배점을 **실행할 때마다 직접 읽어 와서** 채점합니다(정답을 코드에 미리 넣어 두지 않습니다).
- 업로드한 파일이 문제지·정답·OMR 중 무엇인지 자동으로 구분합니다.
- 채점이 끝나면 응시 인원, 평균, 중앙값, 최저점, 가장 많이 틀린 문항 TOP 3, 학생별 채점 결과표를 화면에 보여 줍니다.

### 2. 엑셀 리포트
- **성적 결과** 시트: 위쪽에 전체 개요(평균, 중앙값, 표준편차, 최다 오답 문항), 아래쪽에 학생별 점수와 문항별 O/X
- **문항 분석** 시트: 문항별 정답, 배점, 오답 인원, 오답률, 선택지별 응답 분포

### 3. AI 분석 챗봇
- 학생별 점수·석차 조회, 전체 통계, 많이 틀린 문항 분석처럼 채점 결과에 관한 질문에 답합니다.
- 오답이 많은 문항을 바탕으로 비슷한 유형의 연습 문제를 만들어 줍니다.
- 같은 세션 안에서는 앞서 나눈 대화를 기억하므로 "그 학생은요?" 같은 이어지는 질문도 이해합니다.
- 인사나 "어떤 기능이 지원되나요?" 같은 일상적인 질문에도 자연스럽게 답합니다.

## 기술 구조

### 전체 구성

```
app.py (st.navigation)
 ├─ pages/home.py      1페이지: 서비스 소개
 └─ pages/analyze.py   2페이지: 업로드 · 채점 · 엑셀 추출 · 채팅
        │
        ├─ core/pipeline.py      LangGraph 채점 파이프라인
        │    ├─ answer_key.py    정답 PDF 파싱
        │    ├─ omr.py           OMR 엑셀 로드
        │    ├─ exam_parser.py   문제지 PDF 파싱
        │    ├─ grading.py       채점 · 통계 (pandas)
        │    └─ excel_export.py  엑셀 리포트 생성 (openpyxl)
        │
        └─ core/chatbot/         AI 분석 챗봇
             ├─ guard.py         규칙 기반 가드
             ├─ tools.py         채점 결과 조회용 Tool
             ├─ prompts.py       시스템 프롬프트
             └─ agent.py         create_agent + InMemorySaver
```

### 1) LangGraph StateGraph 채점 파이프라인

각 단계는 하나의 노드이고, 노드끼리는 공통 State(정답표, OMR 데이터, 문제지, 채점 결과, 통계, 엑셀 파일, 오류 메시지)를 주고받습니다.
노드마다 조건부 엣지가 있어, 어느 단계에서든 오류가 나면 남은 단계를 건너뛰고 바로 종료합니다.

```
START
  │
  ▼
[정답 파싱] ──(오류)──────────────────────────────┐
  │                                               │
  ▼                                               │
[OMR 불러오기] ──(오류)───────────────────────────┤
  │                                               │
  ▼                                               │
[문제지 분석] ──(오류)────────────────────────────┤
  │                                               │
  ▼                                               │
[채점] ──(오류)───────────────────────────────────┤
  │                                               │
  ▼                                               │
[통계 계산] ──(오류)──────────────────────────────┤
  │                                               │
  ▼                                               │
[엑셀 생성] ──────────────────────────────────────┴──▶ END
```

파이프라인은 `stream_mode="updates"`로 실행되어, 노드 하나가 끝날 때마다 화면의 진행 상태 표시가 갱신됩니다.

### 2) LangChain create_agent + Tool 기반 챗봇

```
사용자 질문
   │
   ▼
[규칙 기반 가드] ──(차단 대상)──▶ 고정 안내 문구를 즉시 반환 (LLM 호출 없음)
   │ 통과
   ▼
[Agent: gpt-5.4-mini + 시스템 프롬프트]
   │  필요한 값을 Tool로 요청
   ▼
[Tool] ── 채점 결과(pandas DataFrame)에서 계산한 값을 돌려줌
   │
   ▼
Agent가 Tool 결과를 바탕으로 답변 작성 ──▶ 화면에 스트리밍 출력
```

- Agent는 채점이 끝난 뒤 그 결과를 담은 Tool들과 함께 만들어집니다. Tool은 채점 결과를 클로저로 들고 있다가 질문에 필요한 값만 계산해서 돌려줍니다.
- `InMemorySaver` 체크포인터와 세션별 `thread_id`로 같은 세션 안의 대화를 기억합니다.

### 3) 규칙 기반 가드

LLM을 호출하기 전에 정규식 규칙으로 두 종류의 질문을 먼저 걸러 냅니다.
- **프롬프트 인젝션**: 시스템 내부 구성이나 설정을 캐묻거나, 기존 지시를 무시하라고 하는 질문 → 정해진 거절 문구로 답변
- **데이터에 없는 질문**: 출석, 수업 태도처럼 채점 데이터에 없는 정보를 묻는 질문 → "제공된 데이터에 없다"는 안내로 답변

## 기술 선택 이유

1. **채점·통계는 코드(pandas)로 계산**
   채점은 100% 정확하고 항상 같은 결과가 나와야 하므로, 확률적으로 답하는 LLM 대신 코드로 계산하고 LLM은 설명과 문제 생성만 맡습니다.
2. **채점 파이프라인은 LangGraph StateGraph**
   순서가 정해진 단계를 State로 이어 주고, 실패하면 조건부 엣지로 바로 종료하며, 단계별 진행 상황을 화면에 보여 줄 수 있습니다.
3. **챗봇은 RAG 대신 Tool 기반 Agent**
   채점 결과는 표 형태의 정형 데이터라 문서 검색(RAG)보다 Tool로 계산값을 돌려주는 방식이 정확하고 환각이 없습니다.
4. **규칙 기반 가드 + 시스템 프롬프트**
   인젝션 공격과 데이터에 없는 질문을 LLM 호출 전에 먼저 걸러 항상 같은 답을 즉시 돌려줍니다.
5. **InMemorySaver + thread_id**
   요구사항이 "DB 없이 세션 안에서만 기억"이므로 가장 단순하고 충분합니다.
6. **pdfplumber + 정규식**
   텍스트 PDF라 OCR이 필요 없고, 결과가 결정적이며 45문항·배점 합계로 검증할 수 있습니다.
7. **gpt-5.4-mini (reasoning low)**
   계산은 Tool이 하므로 20초 응답 제한에 맞춰 빠른 경량 모델을 선택했습니다.
8. **Streamlit**
   파이썬만으로 UI를 빠르게 만들고 GitHub 연동으로 바로 배포할 수 있습니다.

## 로컬 실행 방법

Python 3.11 이상을 권장합니다.

```bash
# 1. 가상환경 만들기
python -m venv .venv

# 2. 가상환경 활성화
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate

# 3. 패키지 설치
pip install -r requirements.txt

# 4. API 키 설정: .env.example을 복사해 .env를 만들고 키를 입력
#    OPENAI_API_KEY=sk-...

# 5. 실행
streamlit run app.py
```

- `.env` 파일은 `.gitignore`에 포함되어 있어 커밋되지 않습니다.
- Streamlit Community Cloud에 배포할 때는 앱 설정의 **Secrets**에 `OPENAI_API_KEY`를 등록합니다.
- 테스트 실행: `pytest`

## 사용 방법

1. **홈** 페이지에서 서비스 소개를 확인한 뒤 **분석** 페이지로 이동합니다.
2. 왼쪽 사이드바에서 **문제지 PDF, 정답 PDF, OMR 응답 엑셀** 파일 3개를 한꺼번에 업로드합니다.
   파일 종류는 자동으로 구분되며, 인식된 파일 옆에 ✅ 표시가 나타납니다.
3. **분석 시작** 버튼을 누르면 채점 파이프라인이 단계별로 실행되고, 끝나면 통계와 최다 오답 문항, 학생별 결과표가 표시됩니다.
4. 사이드바의 **엑셀 추출** 버튼으로 채점 결과 엑셀 파일을 내려받습니다.
5. 화면 아래 **AI 분석 챗봇**에 질문을 입력하거나 예시 질문 버튼을 눌러 채점 결과를 분석합니다.
   - 예: "평균·중앙값 알려줘", "가장 성적이 저조한 학생은?", "많이 틀린 문제로 유사 문제 만들어줘"

> 엑셀 추출 버튼과 채팅 입력창은 채점이 끝난 뒤에 활성화됩니다.
